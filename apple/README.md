# Locked In — iPhone и Mac

SwiftUI MVP: задачи, проекты с шагами, доски со списками и фильтрами, теги, комментарии, доска и календарь.

## Запуск

1. Открой Planner.xcodeproj в Xcode.
2. Выбери схему Planner и My Mac либо симулятор iPhone; нажми Run.
3. Для серверного режима из ../backend/ запусти make up и make run.
4. Без сервера открой настройки приложения и выбери «На устройстве».

Физический iPhone работает локально; для установки выбери свою команду подписи в Xcode.
Текущий бэкенд слушает loopback на Mac. Доступ с физического iPhone и аутентификация — отдельный этап.
Собранная Mac-версия находится в build/Locked In.app, когда сборка выполнена агентом.

## Основные действия

- + или ⌘N — новая задача. Обязательно только название.
- Боковое меню — доски, дочерние доски-фильтры, теги и завершённые задачи.
- Доска содержит списки. Переключатель «Строки / Столбцы» запоминается локально для каждой доски.
- Общая доска по умолчанию — столбцы, остальные — строки; перенос карточки меняет список задачи.
- Перетаскивай сам список на другой список: порядок общий с дочерними досками, хранится локально и сохраняется после перезапуска. «Входящие» перемещаются вместе с остальными списками.
- Календарь — день/неделя; перетаскивай задачи на время. Двойное нажатие на свободный час создаёт задачу.
- Нижняя ручка блока меняет длительность; редактор доступен нажатием на задачу.
- Шаги проекта и комментарии доступны в редакторе сохранённой задачи.
- Настройки → импорт — перенос задач первого прототипа без удаления исходного хранилища.

Серверный режим и локальный JSON-архив хранят данные отдельно; смена режима не переносит задачи.
Без связи серверная копия доступна для чтения. Локальный режим работает без интернета.

## Код и проверки

Packages/LockedInKit: LockedInDomain, LockedInData, LockedInUI. App/сборка зависимостей — в Planner/.
Исходный прототип сохранён в LegacyPrototypes/ и не входит в сборку.

```sh
swift test --package-path Packages/LockedInKit
LOCKED_IN_TEST_SERVER=http://127.0.0.1:18082 swift test --package-path Packages/LockedInKit
```

HTTP-тест разрешает только выделенный сервер с пользователем apple_mvp_test.

Напоминания: в редакторе задачи переключай уведомление → будильник → выключено; рядом выбери интервал. Час для дат без времени — Настройки → Напоминания. Системный будильник — iOS 26+; на Mac звук с окном остановки работает при запущенном приложении, при закрытом приходит обычное уведомление. Разрешения запрашиваются при первом сохранении включённого режима.

При работающем Mac-приложении напоминание появляется своей анимированной карточкой; «Готово» завершает задачу, «Через 5 мин» переносит сигнал на этом устройстве. После выхода остаётся системное уведомление с резервной задержкой 2 секунды. Тестовая кнопка проверяет оба режима без создания задачи. iPhone-сборка включает LockedInWidgets: Dynamic Island/экран блокировки для ближайшей задачи с точным временем в пределах 8 часов; активность начинается при открытом приложении.
