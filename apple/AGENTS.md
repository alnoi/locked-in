## Архитектура и модель
- SwiftUI, общий Planner.xcodeproj/scheme Planner для macOS и iPhone.
- Packages/LockedInKit: Domain — модели/правила; Data — сеть/хранение; UI — экраны/AppModel; LockedInActivity — общие Live Activity атрибуты. LockedInWidgets — iOS extension.
- Go API: ../backend; контракт: ../backend/api/service/local_tracker/openapi.yaml. Mac/симулятор: localhost:8080; физический iPhone пока локальный.
- Сервер и локальный JSON — отдельные источники, не смешивать. Серверный кеш офлайн только для чтения. Старые SwiftData/локальные данные не удалять и не сбрасывать.
- Доска содержит списки; дочерняя доска фильтрует задачи, сохраняя исходные списки. Проект — задача с детьми, максимум два уровня.
- Обязательно только название задачи. Дедлайн — дата или точный момент; планирование — один старт и независимая длительность.
- Вид доски локальный: общая по умолчанию столбцы, остальные строки.
- listOrderIDs в AppModel — наблюдаемый общий порядок списков; при смене boardID сбрасывать drag preview.
- Порядок списков и задач локальный по источнику/пользователю, общий для родительских/дочерних досок, сохраняется после перезапуска. Фильтрованная перестановка сохраняет позиции скрытых задач.

## Взаимодействия
- Компактные карточки; быстрый ввод внизу списка: название + теги. Клик снаружи: непустое сохранить, пустое отменить; при ошибке оставить текст.
- Mac-редактор: transient NSPopover; повторный клик/клик снаружи закрывает; сохранение явное. Liquid Glass на ОС 26+, иначе material.
- Выбор источника Mac drag: SwiftUI onContinuousHover + экранная область из GeometryReader; NSView.convert не использовать для определения столбца. Событие начатого drag обязательно поглощать (не возвращать через ?? event).
- Mac drag preview: ReorderDragSource.swift — один NSPanel от начала drag до посадки (72% размера, 65% непрозрачности → полный размер и непрозрачность); нативный NSDraggingItem несёт payload с прозрачной картинкой. Не совмещать системную видимую копию и собственную посадку. Источник/provider удерживаются до завершения, успешный reset без второй анимации.
- Перетаскивание: BoardReorderSession/ListDrag.swift, TaskReorderGroup.swift; пружинный preview после 260 мс непрерывного наведения (выход отменяет таймер), сохранение на drop. Свободная область столбца — drag списка; карточка — drag задачи. Карточки перенаправляют drop столбца в общий BoardDropDelegate; мигающей подсветки всего списка нет. Межсписочный перенос/календарь должны работать.
- Напоминания: none → notification → alarm; минуты до plannedAt → deadlineAt → deadlineDate. Будильнику нужно точное время; дата без времени — 10:00, час в локальных настройках.
- Mac: NSPanel-карточка без активации; системный резерв +2 секунды отменяется после показа. Snooze локально сохраняется; изменение/завершение задачи отменяет старый сигнал.
- iPhone: Live Activity ближайшей задачи с точным временем в пределах 8 часов, запуск из активного приложения. Отказ в разрешении не блокирует сохранение задачи.

- Перелистывание: CalendarPageSlide — общий объект направления для входящей/уходящей страницы (обычный динамический .move сохранял прошлое направление). Распознаватель жестов держать вне .id(periodID); повторную навигацию блокировать до завершения перехода. Регрессия: LockedInUITests.
- Календарь: день/неделя/месяц; CalendarPeriodSwipe листает текущий период горизонтально (Mac scrollWheel с фазами, iPhone swipe), во время переноса отключён. CalendarMonthGrid: вертикальная lazy-лента месяцев, подгрузка ±6 месяцев вокруг видимого, стабильный scrollPosition по ID месяца; month-feed не пересоздавать при смене day. Плитка открывает день. В дневном режиме над часами нет повторной даты (она в верхней ленте). Час 60 pt, старт текущий час −1. CalendarSnapping — шаг 15 минут, магнит к границам соседей в пределах 5 минут; точные значения через редактор. Перенос запланированной задачи и resize — общая тень в calendarTimeline: исходный view неподвижен, тень следует без анимации/округления; на отпускании snap + анимированная посадка. Держать тень до завершения mutate, при ошибке вернуть назад. Не менять геометрию области жеста при resize. «Без времени»: ширина текста 170 pt, две строки с обрезкой.
