# Быстрое добавление TrackIt

## Mac

В верхней строке появляется значок прицела, пока TrackIt запущен. Он открывает компактную панель: название новой задачи, прокручиваемый список всех задач на сегодня, общая доска и календарь. Enter сохраняет и закрывает панель; щелчок снаружи сохраняет непустое название. Задачи создаются без дат во входящих общей доски через обычный AppModel, включая офлайн-очередь. «Выйти» из TrackIt завершает и значок; отдельного фонового помощника и автозапуска нет.

В macOS 26+: пункт управления → изменить элементы управления → TrackIt → «Новая задача». Эта кнопка запускает TrackIt при необходимости, предпочитает открытое окно и открывает пустую карточку в общей доске. Существующий незавершённый редактор не сбрасывается: запрос ждёт его закрытия. Без аккаунта сначала нужен вход.

## iPhone: штатная кнопка

Собственная плитка TrackIt в пункте управления и на экране блокировки временно убрана по просьбе пользователя. В симуляторе iOS 27.2 и requestValue, и needsValueError завершались системной ошибкой LNActionExecutorErrorDomain 2010 без показа ввода. Вариант с уведомлениями также удалён. Виджеты «Сегодня» и «Календарь» сохранены.

## iPhone: без открытия TrackIt

1. Один раз открыть TrackIt и войти в аккаунт.
2. В приложении Apple «Команды» создать команду, например «Новая задача TrackIt».
3. Добавить действие TrackIt → «Добавить задачу в TrackIt».
4. В поле «Название задачи» выбрать переменную «Спрашивать каждый раз». Оставить включённым выполнение в фоне; действие само не открывает TrackIt.
5. В пункте управления добавить элемент «Команда», выбрать созданную команду.
6. На экране блокировки: удержать экран → «Настроить» → экран блокировки → заменить нижнюю кнопку на «Команда», выбрать ту же команду.

iOS показывает собственный запрос текста и клавиатуру. Это системный интерфейс «Команд», а не точная копия окна Apple «Напоминания». Отмена ввода не создаёт задачу. Перед выполнением требуется разблокировка; TrackIt не показывает личные задачи на заблокированном экране. Кнопка на экране блокировки доступна в iOS 18+.

При наличии сети задача отправляется на сервер сразу. Иначе сохраняется отдельной командой в App Group и переносится в обычную очередь при запуске/возобновлении TrackIt. Сообщение различает серверное и локальное сохранение. Без ранее открытого аккаунта команда предлагает войти. Данные и команды изолированы по серверу и пользователю, токен остаётся в Keychain. UUID сохраняется при повторной синхронизации, поэтому дубль не создаётся.

## Реализация

- Planner/PlannerIntents.swift включён в приложение и widget extension: OpenQuickTaskIntent (OpenIntent + URLRepresentableEnum), CreateQuickTaskIntent (фон, параметр названия).
- TrackItShortcuts — AppShortcutsProvider в главном приложении; QuickTaskControl — только Mac (macOS 26+, OpenQuickTaskIntent → приложение). Вариант iPhone без открытия приложения остаётся доступен через системный элемент «Команда».
- WidgetQuickTask/WidgetTaskCreation сохраняют отдельные атомарные файлы через WidgetStore; основной OfflineTaskRepository extension не читает и не меняет.
- AppModel импортирует новые команды после загрузки, включая офлайн-кэш. Уже подтверждённые сервером задачи не восстанавливаются поверх более позднего удаления; существующие задачи не перезаписываются.
- Маршруты lockedin://new-task и lockedin://board дополняют прежние ссылки календаря и задач.

Документация Apple: [Controls](https://developer.apple.com/documentation/widgetkit/creating-controls-to-perform-actions-across-the-system), [запуск команд из пункта управления](https://support.apple.com/en-ca/guide/shortcuts/apd06a9201d4/ios), [переменная «Спрашивать каждый раз»](https://support.apple.com/en-eg/guide/shortcuts/apd8b28e2166/ios).
